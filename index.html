ทำตามขั้นตอนเหล่านี้เพื่อเริ่มรัน EA พร้อมการตั้งค่า .set อัตโนมัติ

1

เปิดโฟลเดอร์ข้อมูล (Open Data Folder)

เปิดโปรแกรม MT5 ไปที่เมนู File → Open Data Folder → จากนั้นเข้าไปที่ MQL5 → Experts

2

วางไฟล์ EA (Paste EA File)

คัดลอกไฟล์ EA (สกุล .ex5) มาวางในโฟลเดอร์ Experts → จากนั้นคลิกขวาที่เมนู Navigator แล้วกด Refresh (หรือปิด-เปิด MT5 ใหม่)

3

ลากลงกราฟ (Drag to Chart)

เปิดกราฟคู่เงินและ Timeframe ที่ต้องการ (เช่น XAUUSD, M15) → ลากชื่อ EA จาก Navigator มาวางบนหน้ากราฟ

4

อนุญาตการเทรด (Allow Algo Trading)

ในหน้าต่างป๊อปอัป EA ให้ไปที่แท็บ Common → ติ๊กถูกช่อง Allow Algo Trading และ Allow DLL imports

5

โหลดไฟล์ตั้งค่า (Load .set File)

สลับไปที่แท็บ Inputs → กดปุ่ม Load ด้านล่างขวา → เลือกไฟล์ .set ที่ตรงกับทุนของคุณ → กด OK

6

เปิดระบบเทรดอัตโนมัติ (Start AutoTrading)

กดปุ่ม Algo Trading ที่แถบเมนูด้านบนของ MT5 ให้กลายเป็นสีเขียว → สังเกตมุมขวาบนของกราฟจะมีไอคอนหน้ายิ้มหรือหมวกสีฟ้า แปลว่า EA พร้อมทำงานแล้ว!

อ้างอิงพารามิเตอร์เชิงลึก

เจาะลึกฟังก์ชันการตั้งค่า Inputs เพื่อการปรับแต่ง EA ให้เข้ากับกลยุทธ์ของคุณ

Lot & Distance

การจัดการล็อตและระยะห่าง (Grid Sizing)

LotStart คือขนาดล็อตไม้แรก, LotMultiplier คือตัวคูณล็อตไม้ถัดไป (เช่น 1.05-1.20), และ MaxLot คือการจำกัดเพดานล็อตสูงสุดเพื่อความปลอดภัย

DistanceStart คือระยะห่าง (Pips) เริ่มต้นระหว่างไม้, DistanceMultiplier คือตัวคูณระยะห่าง ทำให้ไม้ถัดๆ ไปกว้างขึ้นเรื่อยๆ (เช่น 1.5x) เพื่อแก้ปัญหาการออกออเดอร์ถี่เกินไปในเทรนด์แรง

Guards & Kill-Switch

ระบบความปลอดภัยระดับพอร์ต (Safety Rules)

SideMaxLossMoney: ถ้ายอด P/L ของฝั่ง Buy หรือ Sell ติดลบเกินค่าเงิน ($) ที่ตั้งไว้ ฝั่งนั้นจะถูก 'แช่แข็ง (Freeze)' ทันที ไม่เปิดไม้เพิ่ม เพื่อป้องกันพอร์ตลากลึก

MaxEquityDD: สวิตช์ปิดฉุกเฉิน หาก Balance - Equity ติดลบเกินค่าเงิน ($) ที่กำหนด EA จะตัดขาดทุนปิดทุกออเดอร์ของหน้าต่างนี้ทันที

MaxSpreadPoints: ป้องกันการออกออเดอร์ในช่วงสเปรดถ่าง (เช่น ช่วงข่าว) โดยกำหนดเป็นค่า Points

EMA Trend Gating

ตัวกรองและหยุดตามแนวโน้ม (EMA Auto-Pause)

UseEMACrossoverPause: หัวใจหลักของ EA คือการหยุดเทรนด์สวนทาง หากเส้น EMA 21 และ 89 ครอสกันชี้ลง EA จะบล็อก (Pause) การออกออเดอร์ฝั่ง Buy อัตโนมัติ (และสลับกัน) เพื่อเทรดตามทิศทางลม

Profit Taking

ระบบรวบปิดกำไร (Smart Netting)

MinProfitToClose_SameSide: จับคู่ออเดอร์ฝั่งเดียวกัน (เช่น Buy คู่ Buy) โดยเอากำไรไม้บวกสุด ไปหักลบไม้ลบสุด ถ้ายอดสุทธิชนะค่าเงินที่ตั้งไว้ จะรวบปิดเป็นคู่ๆ (Pair-Close)

MinProfitToClose_CrossSide: คล้ายกัน แต่เป็นการรวบไม้กำไรฝั่งนึง ไปหักลบไม้ขาดทุนอีกฝั่งนึง (Buy คู่ Sell) ช่วยแก้ปัญหาไม้ติดค้างได้อย่างเป็นระบบ

OppPyra Hedge

เปิดไม้แก้ฝั่งตรงข้าม (Opposite Pyramid)

ฟีเจอร์เด่นเฉพาะใน DocStrange EA: เมื่อเปิด OppositePyramid_OnFreezeLoss = true หากมีฝั่งใดถูก Freeze ด้วยการขาดทุน ระบบจะเปลี่ยนวิกฤตเป็นโอกาส ด้วยการเปิดไม้อีกฝั่งนึงเพื่อทำกำไรและสร้าง Rebate

สามารถควบคุมได้เข้มงวดด้วย OppPyra_MaxLayers (จำนวนชั้น), OppPyra_MaxTotalLot (เพดานล็อตสูงสุดของการ hedge) และ ProtectEquityDD
