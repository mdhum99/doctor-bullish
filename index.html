การติดตั้ง EA ลงใน MetaTrader 5

ทำตามขั้นตอนเหล่านี้เพื่อนำไฟล์ .ex5 และ .set เข้าสู่ระบบ

1

เปิดโฟลเดอร์ข้อมูล (Data Folder)

เปิดโปรแกรม MT5 ไปที่เมนู File → Open Data Folder → จากนั้นเข้าไปที่ MQL5 → Experts

2

วางไฟล์ EA

คัดลอกไฟล์ EA (.ex5) มาวางในโฟลเดอร์ Experts → ปิด-เปิด MT5 ใหม่ หรือกด Refresh ที่ Navigator

3

อนุญาตการเทรด (Algo Trading)

กดปุ่ม Algo Trading ด้านบนให้เป็นสีเขียว → ลาก EA ลงกราฟ → ที่ Common ติ๊ก Allow Algo Trading และ Allow DLL imports

4

โหลดไฟล์ตั้งค่า (.set)

แท็บ Inputs → กด Load → เลือกไฟล์ .set ที่ตรงทุนของคุณ → กด OK → สังเกตไอคอนหน้ายิ้มหรือหมวกสีฟ้ามุมขวาบน

อ้างอิงพารามิเตอร์หลัก

คำอธิบายตัวแปรสำคัญในหน้า Inputs

LotStart & Multiplier

การจัดการล็อต (Lot Sizing)

LotStart คือขนาดล็อตไม้แรก ส่วน LotMultiplier คือตัวคูณเมื่อเปิดไม้ถัดไปแบบ Grid (ควรตั้งไว้ต่ำ เช่น 1.05-1.20) และ MaxLot คือการจำกัดเพดานล็อตสูงสุด

DistanceStart

ระยะห่าง (Grid Distance)

ระยะเริ่มต้น (หน่วย Pips) ระหว่างไม้ก่อนหน้ากับไม้ถัดไป ค่า DistanceMultiplier คือการขยายระยะให้กว้างขึ้นเรื่อยๆ

SideMaxLossMoney

ระบบแช่แข็งฝั่งขาดทุน (Per-Side Freeze)

หาก P/L ฝั่งใดฝั่งหนึ่งติดลบเกินค่าเงินที่ตั้งไว้ ฝั่งนั้นจะถูก Freeze (ไม่เปิดไม้เพิ่ม) เพื่อป้องกันการลาก

MaxEquityDD

สวิตช์ปิดระบบฉุกเฉิน (Kill-Switch)

หาก Equity ลดลง (Balance - Equity) เกินค่าเงินที่ตั้งไว้ EA จะปิดทุกออเดอร์ของหน้าต่างนี้ทันทีเพื่อตัดขาดทุน

OppositePyramid

เปิดไม้แก้ฝั่งตรงข้าม (Hedge Recovery)

เฉพาะใน DocStrange EA: เมื่อฝั่งหลักถูก Freeze ระบบจะเปิดไม้ Hedge ในทิศตรงข้ามเพื่อสร้าง Cash Flow และถัวเฉลี่ย

KVB Broker Rebate

สมัครผ่าน IB รับเงินคืน 40 USD ต่อ 1 Lot การเทรด

สมัครเปิดบัญชี KVB →
